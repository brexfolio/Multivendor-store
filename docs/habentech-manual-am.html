ተሰርዟል / ተመልሷልስቶክ ይመለሳል በራስ-ሰር (የመመለሻ ግብይት ይፈጥራል)

የምርት ጥያቄዎች

አስተዳዳሪው ጥያቄውን ተጠናቋል / ተሽጧል / የማይገኝ በማድረግ — ደንበኛው በቴሌግራም በራስ-ሰር ገራጋሪ መልእክት ይነገራል።

💬 የሽያጭ ጥያቄዎች

ደንበኞች ሊሸጡ የሚፈልጉት መሳሪያዎች።

  • የደንበኛውን ማስታወቂያ ይመልከቱ (ሞዴል፣ ሁኔታ፣ የሚጠበቅ ዋጋ፣ ፎቶ)።
  • በክለሳ ላይ አመልክት (በቦት አዝራር) ሂደቱን ለመጀመር።
  • ደንበኛውን ቅናሽ ይላኩ፤ እሱ በአፕ ውስጥ ይቀበላል/ይቃወማል።

📈 ኢንቬንቶሪ እና ስቶክ አስተዳደር

የአስተዳዳሪው እውነተኛ እልልል። ይህ ክፍል ስቶክን፣ ግብይቶችን እና እንዴት ስቶክ ከትዕዛዞች ጋር እንደሚስማማ ያስረዳል።

ስቶክ ለእያንዳንዱ ምርት ይከታተላል

  • እያንዳንዱ ምርት ከጠቅላላ ብዛት ጋር የኢንቬንቶሪ መዝገብ አለው።
  • እያንዳንዱ ለውጥ እንደ ግብይት ይመዘገባል (የኦዲት መዝገብ)።
  • ስቶክ መቼም ከ 0 በታች አይወርድም (በዳታቤዝም ተፈጻሚ፣ quantity >= 0)።
ግብይትውጤትምሳሌ
መጨመር (Add)+ ስቶክከአቅራቢ መሙላት፣ ግዢ
ማውጣት (Remove)− ስቶክመጎዳት፣ መጥፋት፣ የእጅ ማስተካከያ
ማስተካከል (Adjust)ወደ አንድ ቁጥር ያዘጋጃልየክምችት መጠን እርማቶች
ሽያጭ (Sale)− ስቶክ (በራስ-ሰር)ትዕዛዝን ማጠናቀቅ
መመለስ (Return)+ ስቶክ (በራስ-ሰር)ትዕዛዝን መሰረዝ/መቀልበስ

የእጅ ስቶክ ስራዎች (በአፕ)

በ ኢንቬንቶሪ ክፍል ውስጥ ምርቱን ከፍተው፦

  • ስቶክ ጨምር — ብዛት፣ አማራጭ የዋጋ ውድ እና አቅራቢ። አዲሱን ድምር ያሳያል።
  • ስቶክ አውጣ — ምክንያት ከዝርዝሩ ይምረጡ። ተረጋግጧል፦ ካለው ብዛት በላይ ማውጣት አይችሉም።
  • ስቶክ አስተካክል — ብዛቱን ወደ አንድ ቁጥር ያዘጋጃሉ ከምክንያት ጋር።

እያንዳንዱ ስራ ለዚያ ምርት በ ግብይት ታሪክ ውስጥ ይመዘገባል።

ትዕዛዝ ስቶክን እንዴት ይቀይራል (ራስ-ሰር)

ትዕዛዝ ተቀመጠ→ አስተዳዳሪ ጨርስ ተጫነ→ የሽያጭ ግብይት ተፈጠረ→ ብዛቱ ቀነሰ→ አቅርቦቱ ተዘመነ
የመከላከያ ጠባቂ፦ በዳታቤዝ ውስጥ የተጨመረ ልዩ ጠቋሚ አንድ ትዕዛዝ አንድ ሽያጭ እና አንድ መመለሻ ብቻ መፍጠር እንደሚችል ያረጋግጣል — አስተዳዳሪው ሁለት ጊዜ ጨርስ ቢጫን እንኳን። ሁለት ጊዜ መቀነስ አይቻልም።

አቅርቦት & ዝቅተኛ ክምችት

  • አቅርቦቱ በራስ-ሰር ከስቶክ ጋር ይስማማል።
  • ስቶክ 0 ሲደርስ → አቅርቦቱ ከክምችት ውጭ ይሆናል (ማዘዝ አይቻልም)።
  • ከ ዝቅተኛ የስቶክ ደረጃ በታች → ዝቅተኛ ክምችት ተብሎ ማንቂያ ይችላል።
ለእርስዎ (ባለቤት)፦ ስቶክን የሚጠብቁት ሁለቱ ልዩ ጠቋሚዎች በ supabase/schema_sell_and_inventory.sql ውስጥ ሲሆኑ በ ቀጥታ ሱፓቤዝ ዳታቤዝ (SQL Editor) ላይ መተግበር አለባቸው። የቬርሰል ማሰማሪያ የአፕ ኮድን ብቻ ነው የሚልከው — የዳታቤዝ ለውጡ በእጅ ነው።
